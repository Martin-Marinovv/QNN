BROADCAST FLOW REFERENCE

WITH VIDEOS:
┌─ QNN standby (msg s) → [CRT] → First frame frozen (preroll s) → Video plays to end → Last frame frozen (postroll s) → [CRT] → !apply (oi s) → [CRT] → QNN standby → next video … (loops)

NO VIDEOS (all PLAYLIST entries commented out):
┌─ QNN standby (msg s) → [CRT] → !apply (oi s) → [CRT] → QNN standby … (loops)

SCREEN GUARANTEE: QNN or !apply always showing. CRT static only during transition flashes.

ASSETS — assets/ folder

assets/terminal-frame.png — frame overlay, must be 1920×1080px. Transparent centre reveals panels and video.
assets/broadcast-01.mp4 … broadcast-06.mp4 — your video files. Edit the PLAYLIST array at the top of index.html to match your filenames. Videos play in order to their natural end. Comment ALL entries out to run in no-video mode.

SETUP GUIDE

1. Add assets/terminal-frame.png
5. Set OBS browser source to 1920 × 1080
2. Add video files as broadcast-01.mp4 etc.
6. Right-click → Properties → tick Control audio via OBS
3. Edit PLAYLIST in index.html with your filenames
7. Adjust timing → Generate URL → paste → Refresh
4. Push to GitHub → Settings → Pages → main branch
8. Eye icon hides visuals AND mutes audio
